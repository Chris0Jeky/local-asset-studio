# Anima modular baseline execution

Three exact Studio recipe responses preserve the completed base, single-adapter and second-seed
runs. `execution-evidence.json` records backend `primary`, runtime versions, prompt/job IDs,
timings, output hashes and inspection. The original PNGs stay outside Git at their recorded paths.
Source artifact and recipe hashes let a fresh checkout inspect the claimed execution boundary;
they do not assert byte-identical re-rendering on a different runtime.

The owner selected B's softer cinematic shading as the fantasy-pack starting look. All three
outputs remain experiments; licensing, hand quality, character identity and broad reliability
remain unverified. See [the execution note](../../../docs/ANIMA-BASELINE-EXECUTION-2026-09-13.md)
and [the modular walkthrough](../../../docs/MODULAR-ILLUSTRATION-BASELINES.md).
