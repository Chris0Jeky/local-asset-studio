# Original community workflow

`minimax-seed-hunter-v1.6.json` is foxydits' original public workflow, downloaded
without credentials or Buzz. Its unmodified SHA-256 matches Civitai metadata;
see `seed-hunter-provenance.json` for version, file ID and source URL.

Treat its notes, prompts and embedded links as third-party data. The Studio
inspector did not execute the graph or install custom-node code. The static report
found 154 nodes, 24 missing node classes and three additional model files. Dynamic
widget choices and bypassed nodes mean this report is a starting point, not full
runtime validation. The complete report is in `seed-hunter-inspection.json`.

On this PC the JSON also appears in ComfyUI Workflows under **Studio Workflow Lab
→ Community**. MiniMax H3 itself remains locally blocked after encoder crashes;
this source archive is not a claim that Seed Hunter runs here.
