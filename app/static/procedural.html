    2. Prepare locally

    You can explore and check settings before installing the tools. Preparing saves a recipe and checks its files; it does not run Blender.

    Setup instructions

    Set absolute blender and node executable paths in config/local.json. These generators require Blender 5.4; the general example configuration may point to an older Blender.

    Install the repository’s pinned Khronos validator once:

    npm ci --prefix tools/gltf-validation --ignore-scripts

    Add an absolute godot path to enable import checks. A detected file does not prove its application version or compatibility.

    3. Start and inspect

    Your prepared plan will appear here. Open it in Comparisons and choose Start build explicitly.

    Finished builds appear in the Library with their recipe. Inspect the model, sheet and checks before accepting the art or using it in a game.
