    GO DEEPER, ONE LAYER AT A TIME
    A workflow is a recipe you can reshape.
    Start with a working pipeline. Change one meaningful thing. Keep the recipe with the result.
    01 / THE FUNDAMENTALS
    What makes a generation?
    PromptEncoderModel + samplerVAEOutput
    Checkpoint / diffusion model
    The visual engine. A checkpoint may bundle the encoder and VAE; split models need companion files.
    Text encoder
    Turns your words into conditioning. Match it to the model family; a similar filename is not enough.
    VAE
    Converts compressed latents into pixels, video, audio or geometry. Video models may need two decoders.
    LoRA
    A smaller adapter for style, lighting, motion or identity. Match the base family, use its trigger words, then compare strengths at a fixed seed.
    ControlNet / image reference
    Guide pose, edges, depth or appearance. They give more control than adding more words to the prompt.
    02 / AN EXPERIMENT THAT TEACHES YOU SOMETHING
    Audition → choose → finish
    1. Audition three seeds. Keep the prompt, model and dimensions fixed. Look for composition and silhouette.
    2. Lock the seed. Change only LoRA strength, lighting, or prompt wording. Pin two outputs to compare.
    3. Refine the winner. Try low-denoise refinement, targeted face/hand repair, then an upscaler.
    4. Expand the asset. Send your image to video or 3D as a reference. Save the recipe at each stage.
    An upscaler adds pixels. It cannot guarantee better anatomy, consistent characters, or useful topology.
    Choose controls with a purpose
    Seed
    A repeatable starting point. Reproducibility also depends on the same model files, workflow and runtime.
    Steps / CFG
    Follow the model's recipe. Turbo models often use fewer steps and very low guidance; more is not automatically better.
    Frames / resolution
    Both increase video memory and time. Preview small, then raise one at a time.
    03 / BRING YOUR OWN WORKFLOW
    Inspect before you run
    Drop in a ComfyUI workflow JSON to see missing nodes and model filenames. Inspection never queues a generation or installs custom-node code.
    Open the original in ComfyUI to edit connections. Community graphs can depend on different GPU backends, model versions, or paid API nodes.
