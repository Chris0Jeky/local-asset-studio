One service. Human or agent.

Registered recipes use the existing Studio worker. Prepare a pinned ticket, approve it explicitly, then observe the retained job. Reusing the same ticket does not create another attempt.

python app/server.py --repo-root .
python -m studio_workflow capabilities
python -m studio_workflow documents list
python -m studio_workflow documents get DOCUMENT_ID
python -m studio_workflow catalog
python -m studio_workflow prepare --recipe recipe.json --out ticket.json
python -m studio_workflow run --ticket ticket.json --approve
python -m studio_workflow status JOB_ID
python -m studio_workflow wait JOB_ID --seconds 600

Run commands from the repository root, with the normal local configuration. A recipe is a registered preset_id, its controls and batch_count: 1. A new ticket means a new deliberate attempt, not recovery from an uncertain one.

Document edits and graph exports are not execution authorization. See docs/workflow-studio/SHARED-DOCUMENTS.md and docs/workflow-studio/STEPS-AND-SAVING.md for shared editing, recovery and the remaining boundaries.
