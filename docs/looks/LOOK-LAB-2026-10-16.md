## Method and receipts

In round 1, for each of 14 lighter looks: the shipped example/default seed, then an original SFW scene/new seed. Same-origin POSTs go only to the running Studio at `http://127.0.0.1:8191`, using `/api/looks/prepare` then `/api/jobs`, `batch_count: 1`, and labels starting `Lab 1016 · `. Exact requests are in [the journal](lab-2026-10-16.journal.jsonl). The service uses the primary checkout; editing this worktree does not change its saved Workspace looks. Variants therefore prepare the existing look and override only the tested bound control in the job request. The three pose tests use the registered reference-capable presets through `/api/jobs`; a Look itself cannot accept a reference picture.

Studio's actual output route is `/api/image/<job-id>/<index>`, as used by Make. `/view?...` on Studio returned 404; the internal ComfyUI route is `/view`. Image retrieval was corrected without resubmitting any generation. Every scored image was opened; faces, hands, animal faces/paws and named small props were cropped at native resolution. Pixel raw and 128px export files were both opened. The one skipped image received no score or crop review.

[The receipt manifest](lab-2026-10-16.receipts.json) records all 81 job/prompt IDs, exported-recipe/workflow hashes, 91 output hashes, dimensions, source paths, sizes and exact RGB colour counts. Existing inventory pins/source URLs/terms for the 37 model components referenced by the exported workflows are included. Those pins are existing metadata, not an independent rehash or licensing audit tonight. No model was acquired. Full exported recipes, downloaded originals, crops and comparison keys are in ignored `.runtime/lab-20261016/` and `.runtime/lab-20261016b/`; the running Studio also retains its own job recipes and originals. Preserve that ignored directory before this worktree is removed.

Where the full evidence lives: each job's complete `recipe.json` and submitted `workflow.json` are kept by the Studio under its `experiments_root` (`config/local.json`; on this PC `C:/Users/jekyt/source/local-asset-studio/experiments/runs/<job-id>/`), keyed by the job IDs in the journal and manifest, and their hashes are in the manifest so a copy can be checked. The judged outputs, crops and per-job JSON are copied to the main checkout's ignored `.runtime/lab-20261016/` and `.runtime/lab-20261016b/`. Images stay out of Git by policy.

The [rubric](../quality/JUDGING-RUBRIC.md) governs scores and minimum-criterion verdicts. Anatomy is null for objects; control is null without an input. R2 pixel variants and R3 candidates had shuffled labels, were scored, then their keys were read. Existing baselines had already been seen; other single-candidate R2 wording tests were configuration-aware and marked `blind: false`. This is partial blinding, not a fully blind benchmark. Differences within 0.3 are ties. Two-scene tests and one-seed stack tests cannot establish general superiority.

## For agents: concrete rules learned

1. Match Make's request shape and use one job at a time. `waiting` is active, not a final state. Capture job ID before polling and prompt ID as soon as it appears. A media 404 is not a reason to rerender. Check Studio and ComfyUI queues before every submission.
2. Read the GPU lease before submissions. Tonight's legacy lease was unheld/stale (September); the owner's current exclusive assignment was recorded explicitly. Do not claim its note was updated: it is outside this worktree's writable roots. Stop if a coordinator takes the lease.
3. Round 2 resolves the CIM admission blocker by explicit owner instruction: read `/api/health` `host_commit.committed_bytes / host_commit.limit_bytes`; submit Krea/Flux only below 0.60. Capture `gpu_memory` and `vram_guard` too. If commit is high, wait two minutes and recheck for at most twenty minutes, then defer and return later. Never use the denied CIM probe or substitute physical-RAM percentage.
4. Separate cold loading, CPU text encoding, sampling and VAE spill. Warm WAI/Animagine inference was about 10 seconds; Anima around 16-22 seconds. Z-Image prompt encoding dominated 94-193 second totals. Several SDXL/Anima jobs reported 1.8-2.9 GiB transient shared-memory spill that drained. No fivefold sampling-step slowdown was observed; nothing was restarted or reconfigured.
5. Keep model dialect and stack architecture intact: SDXL anime quality tags/tails, Anima artist tags and model-only slots, Z-Image prose. Do not put Illustrious LoRAs into Anima or assume any six-slot stack is compatible. Strength zero prunes disabled nodes; all baseline-off adapters remained off.
6. A seed change is not an ablation. R1 intentionally changes scene AND seed to probe transfer; R2 uses exact per-scene baseline seeds. R3 holds one prompt/seed fixed while changing stacks. Do not promote a tie, a one-scene improvement, or a good mean with a fatal missing prop.
7. Subject scale and crop terms can fight the scene: `wide shot`/`scenery` reduced faces and lost reading; `upper body`/`dutch angle` did not preserve held objects; generic "all props visible" wording failed. This is a measured failure, not a new universal prompt rule.
8. A body skeleton is not identity or fingers. For empty hands only, `both hands relaxed closed fists` improved this WAI pose. Record control separately from anatomy. Do not apply the workaround to a brief requiring an open palm or held prop.
9. Keep successful generation, agent judgement, human acceptance and licensing distinct. No human choice was ticked. Images of skipped subjects are not proof thumbnails.

10. Fixed-scene seed reliability is a different question from two-scene transfer. Keep every control and the full compiled prompt identical, vary the seed only, and report KEEP / submitted seeds. Do not pool different scenes into one seed keep rate or count FIXABLE as KEEP.
11. Count shared grips and duplicated props. Pearly put a separate instrument in each hand in both astronomer seeds; Night Shift duplicated a stool in one bakery seed. A clean face does not rescue the named relationship under R2.
12. Check unrequested writing: librarian context added garbled book titles in both AniFox seeds, jar labels failed in Airy, and one One Obsession seed produced a large magazine masthead. Blank-label/no-cover wording is a future configuration, not a tested repair tonight.
13. Explicit adult wording helped the new Nijisis scene; it does not qualify the youthful default. Both default Krea witches were skipped after initial screening, with no crop review, score or promotion. Never reopen skipped output for a thumbnail.
14. Below-threshold admission does not guarantee low in-flight commit or no spill. All Krea submissions entered below 60%, but jobs spilled shared GPU memory and Atelier took 1,309 and 2,205 seconds. Record actual elapsed time; never restart to chase a speed claim.
15. Resolve Make thumbnails through recipe lineage, bundle examples, anchor and existing preset proofs. All 23 sources existed and served images, so step 3 added an inventory README and zero redundant JPEGs. Do not alter Make wiring or replace an existing preview merely to fill a new directory.

16. Match Combine's input kind. Make's `standing`/`bent` drawings use thin-line `studio.coco18-lines/v1` and the skeleton route; picture routes need pictures. Replace-character keeps the scene outfit and style, so use `outfit`, not the source `clothes`, for that fill.
17. Judge identity and rendering separately from body control. Round 3 depth followed the pot silhouette while leaving a blank grey face; plain 9B changed the apparent age. Good pose control does not qualify those outputs as identity transfer.
18. A close-up source expanded to full body invents hidden clothes, shoes and anatomy. Standing guides did not produce the requested closed hands; bent guides lost the look-back and hid or changed leg crossing. Crop feet as well as hands and faces.
19. Tune adds named Anima adapters through bound `loraN`/`loraN_name` slots; keep Petiflow at 1.0 for this ablation and other unused slots off. The settings library is `presets/settings-kb.json` here. Read installed options; never infer compatibility from a slot alone.
20. Compare the named plant/prop as well as the face. Several round-3 adapter variants changed divided fern-like fronds into a broad-leaf plant; a clean face did not erase the adherence penalty. A neutral KEEP does not establish an improvement, and means within 0.3 remain ties.
21. Do not rewrite general LoRA strength ranges from one scene/seed. Report useful local starting values and the categorical failure; broader strength recommendations require more scenes/seeds.
