## Suggested execution order and ownership

1. **Foundation:** provider intake/model bundles, current capability probe, resource preflight. Extend cheap discovery (#1) and isolated backend switching (#2), not parallel replacements.
2. **Useful local output:** anime/reference/repair acceptance benchmark and adapter portfolio. Extend experiments (#3) and the existing Lanternkeeper assets.
3. **H3 baseline:** native graph plus complete dependency lock; only then seed staging/cache, continuation and upscale comparisons.
4. **Independent comparisons:** LTX-2.5, Wan2.2 and documented VACE. Keep each environment and model bundle explicit.
5. **3D and finishing:** topology/material/rig checks, deterministic sprites, engine export; optional music and HyperFrames campaign assembly.

Read-only researchers can work concurrently on separate sources. A runtime operator owns environment/queue changes. A workflow implementer owns graph/schema work. A reviewer checks reproducibility and evidence. They must not all write the same checkout, install into the same Python environment or queue competing GPU jobs.

## Minimal benchmark contract

Use a short reusable test set: a fantasy character holding a compass; a three-panel dialogue; a fixed-camera observatory; a protected-logo product edit; a door-opening video with hand contact; a small textured prop; and a directional sprite animation. Keep prompts and reference assets stable within a comparison. Record model/graph hashes, runtime versions, stage timings, memory measurement method, defects, accepted outputs and cleanup time. Do not claim cross-family equality from the same seed or step count.

## What this pass did and did not do

Delivered: source-linked research catalog, staged blueprints, architecture, offline browser, deterministic bounded experiment planner, limited header inspector and isolated unit tests. The browser exports research selections; the planner exports non-executable experiment intents.

Not performed here: access to the user's local disk/GPU; new model downloads or inference; source-faithful reproduction of the inaccessible Civitai image/graph; acceptance of gated terms; commercial licensing; paid worker provisioning; or integration of proposed runtime/shot/3D features into the live app. Source-page review is not a full security audit of all linked repositories. Existing successful runs remain documented in CURRENT_STATE.md and were not re-run by this research pass.
