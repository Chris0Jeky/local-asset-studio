## Existing work is not new work

The observer, reducer, job-window recording, integrity inspector and paired-observation report are already in the inspected tree. The Windows host-commit gate already exists. Browser headless launch and some visibility-aware observation already exist. Workspace already has content-addressed sources. Their wider acceptance and remaining work stay with their existing issues.

Do not reopen old tasks from the PDF's assumptions. The recorded page-file change and owner restart are complete; #77/#89 native/host failure investigations are not resolved by that fact or by this package. #359 retains telemetry review concerns. #360/#361 retain crop-retention/base64 and other review findings; neither is silently fixed here.

## Decisions deliberately left open

The exact profiler activity/kernel support of the owner's current build, the dominant inference operator, safe pinning budget, useful compile buckets, derivative cache quota and whether any new graphics format is justified are **not established**. Each has a named experiment or existing owner rather than a guessed default.

Do not schedule new model comparisons, alter launch flags, change precision, clear model caches, increase paging, close browsers, reorder user jobs, install kernels or update drivers as a side effect of these docs or CPU changes. Any later action uses existing authority, fresh queue/resource checks and a finite allowance.

## Completion language

Planning delivered means these documents exist. CPU implementation verified means exact tests and the scoped benchmark were run. Integrated means the complete candidate tree passed repository gates. Windows inference improvement requires separate owner-machine evidence. Creative acceptance, model terms and engine delivery remain independent decisions.
