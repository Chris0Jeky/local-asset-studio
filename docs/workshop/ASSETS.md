The ambience art is decorative and has empty semantics. It carries no label, instruction, progress, readiness claim or button. It does not cover prompt fields, controls or errors. Ambience None reserves no empty region.

The selected ambience is not treated as proof that a file, provider or backend is available. The policy uses a bounded `available | missing | unknown` local asset observation. A missing or unconfirmed poster falls back to theme tokens and a quiet HTML status; it never triggers a download or disables the workbench. Internet and backend observations do not gate an available local poster.

Every SVG source contains only ordinary vector shapes, gradients and filters. There are no scripts, `foreignObject`, external references, fonts, remote URLs or executable configuration. Production does not insert prototype artwork into the real result gallery. The real gallery continues to show the user's outputs and provenance.

Existing examples retain their existing provenance and terms. This document does not relicense model outputs, certify character rights, treat a passing frontend test as artistic acceptance or claim that the visual environment was produced by an installed Studio model.

`app/static/workshop-immersive.css` remains the stable visual-system entrypoint and imports the core before applying narrow responsive overrides. `workshop-ambience.css` is a separate effective-state layer, so reverting the eligibility slice does not change the poster sources or user preference format.

Use normal platform fonts. Future skins/environments must remain allow-listed presentation data, not generation defaults or backend state. Motion, local loops, parallax, audio and remote media remain outside this delivery and require separate provenance, resource and execution qualification. Run the full presentation-state, fallback and viewport contracts for each addition.
