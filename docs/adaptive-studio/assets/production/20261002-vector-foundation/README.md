# Local Asset Studio icon source inventory

This source-only inventory selects 40 semantic mappings from the already acquired Tabler outline family. All 62 glyph files and the MIT licence are byte-identical to the pinned v3.48.0 source manifest. Alternatives remain available without being implied product requirements.

Open `preview.html` locally. It contains inline copies for visual review; original source SVGs remain unchanged. Each glyph uses a 24 × 24 viewBox, a 2-unit stroke, rounded caps/joins and currentColor. A real control must have its visible HTML label or accessible name. Decorative inline SVG should have aria-hidden="true" and focusable="false". Do not rely on an external SVG img inheriting host currentColor or CSS variables.

These are prepared assets, not a shipped navigation change. Status meanings are not reassigned: execution complete is not artistic approval, uncertainty is not failure, and a recovery-record icon does not authorize retries. Native control hit targets, keyboard behavior, full six-skin contrast, OS forced-colours behavior and application integration still require runtime verification. The static inventory has no scripting, event handlers, remote resources, embedded raster images or motion.

The pinned MIT licence is in `icons/tabler/LICENSE` and must accompany redistribution. Source attribution and exact hashes are in `SOURCE-MANIFEST.json`. `semantic-map.json` provides stable meanings and suggested HTML labels.

## State/helper source specimens

The 12 helper SVGs include 11 semantic state illustrations and one synthetic target-region mask. Original folio/frame compositions use Tabler paths where appropriate under the bundled MIT licence. They are decorative, inline currentColor SVGs. Keep actual state labels and actions in HTML; hide decorative illustrations in forced-colours if needed. Prefix the mask pattern ID and its local fill reference per inline instance to avoid duplicate document IDs. No model mask capability, status behavior, retry operation or application integration is implemented here.

Visual QA used Sharp raster renders in two explicit palettes, at actual source-preview sizes. The cloud browser refused the local preview address (ERR_BLOCKED_BY_CLIENT); HTML layout, OS forced-colours, all six runtime skins and app keyboard behavior were not tested. No browser workaround was used.
