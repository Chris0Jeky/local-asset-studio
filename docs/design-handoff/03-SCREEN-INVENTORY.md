# 03 · Screen inventory

Every current screen, its regions, its states and what is wrong with it. Screenshots are in [screenshots/](screenshots/).

**How they were taken.** 39 of the 42 screenshots come from the real frontend files served by the repository's UX test
fixture (`tests/studio_use_cases.py` → `build_handler()`, synthetic API data, public-safe example pictures, no ComfyUI,
no generation) at 1440×900 or 390×844, reduced motion. Three (`80-`, `81-`, `82-`) are the owner's live Studio,
navigation only, with every image hidden before capture; the only non-GET requests were the Studio's own read-only
`/api/estimate` calls. Full-page captures of pages with a fixed run dock show the dock mid-page; that is a capture
artifact, not a layout bug.

Legend for **Problems**: `[measured]` = counted by `tests/studio_use_cases.py` or live QA; `[code]` = confirmed in the
source; `[seen]` = visible in the screenshot; `[owner]` = owner's own words.
