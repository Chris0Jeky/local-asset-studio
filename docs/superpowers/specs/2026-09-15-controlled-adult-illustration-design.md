# Controlled Adult Illustration Design

**Status:** approved programme foundation for #403  
**Research freeze:** 15 September 2026  
**Baseline:** `b29205cfc95ca4e64d72ae38d53df30c83968997`

## Goal

Add a model-independent, evidence-aware control layer for adult-only sensual/anime illustration that reuses Prompt Lab, Reference Intelligence, Workflow Studio, Production, model bundles, character consistency and Repair Studio.

## Chosen design

Use one reviewed illustration intent, explicit source/reference roles, inspectable geometry artifacts, exact route cards, qualified adapters, transparent genre packs and finite benchmark evidence. Compile these records onto existing setup/workflow/execution services. Research manifests are static input and never executable authority.

## Alternatives rejected

- **One universal checkpoint/LoRA stack:** fast initially, but entangles identity, pose, body, outfit and style and cannot explain failures.
- **A second specialised Studio/server:** duplicates queue, storage, recovery and agent semantics.
- **Prompt-only semantic compiler:** cannot enforce geometry, slot ownership or pixel scope.
- **Install-first model catalogue:** increases environment risk and choice before a task-based baseline exists.
- **Full custom posing/painting canvas:** duplicates Blender/Krita/Comfy and delays the useful vertical slice.
- **Autonomous critic/promotion:** conflates model observation, artistic acceptance and rights decisions.

## Constraints

- Public fixtures are synthetic, adult-only and non-explicit.
- No inference, install, download, training or publication follows from a manifest.
- No second model registry, store, queue, executor, reviewer or native editor.
- Exact route/configuration evidence; no family-wide compatibility claim.
- Expected-revision commands and durable request identities for later writes.
- Read/inspect/compile/plan/prepare create zero generation jobs.
- Agents cannot infer adult status, consent, acceptance, rights or promotion.
- Preserve `HUMAN_TODO.md`.

## Success

The first useful proof is one approved adult original character, one authored pose/silhouette composition, one role-separated appearance source, one fast versus quality route comparison, retained failures and an owner-accepted reusable image. Broader packs, training and automation follow only after that gate.
