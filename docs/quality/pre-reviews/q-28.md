The lab re-proved the four Combine routes on an adult original pair: the fantasy pack's traveller portrait, put into a
spellcasting pose, three seeds per route, through the Studio (#875). The review agent judged the twelve outputs blind

fantasy pack's full body. It still carries the pose and costume, so it works only as a first stage before the replace
route.
